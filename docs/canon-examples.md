# Canon för exempel

## Huvudcase

Tullmyndigheten Atlantis hanterar varuflöden, deklarationer, riskbedömningar, kontroller, ärenden och digital service. Caset ska användas för att illustrera begrepp utan att bli en detaljerad beskrivning av faktisk tullverksamhet.


## Huvudscenariofamilj

Bokens återkommande huvudscenariofamilj består av fem närliggande situationer:

- digital tullklarering
- riskbedöma varuflöden
- hantera inkommande deklaration
- begära och hantera komplettering
- genomföra kontrollåtgärd

Dessa situationer ska återanvändas för att visa hur samma verksamhetsområde kan beskrivas som förmåga, process, rutin, tjänst, information, regel eller ansvar beroende på syfte.

## Regler för exempel

- Exemplen ska vara förenklade och pedagogiska.
- Undvik detaljer som kan uppfattas som operativa instruktioner för att kringgå kontroll.
- Använd samma begrepp och namn konsekvent.

## Kapitel 8: Val av beskrivningstyp

Exempelområdet är fortsatt Tullmyndigheten Atlantis deklarations- och kontrollverksamhet.

Återkommande principer:

- Om ledningen vill prioritera investeringar börjar analysen ofta med förmågor.
- Om arbetet fastnar mellan roller och organisatoriska enheter börjar analysen ofta med process eller värdeflöde.
- Om handläggare gör olika i liknande fall börjar analysen ofta med regler, rutiner och exempel.
- Om ett utvecklingsteam behöver bygga digitalt stöd behöver process, information, regler och produktbeskrivning kombineras.
- Om ansvaret är oklart behövs roll- och ansvarsfördelning, inte bara mer processdetaljer.


## Kapitel 9: Identifiering och avgränsning

Exempelområdet är fortsatt Tullmyndigheten Atlantis deklarations- och kontrollverksamhet, med särskilt fokus på riskbaserad deklarationskontroll.

Återkommande kandidater:

| Kandidat | Rekommenderad tolkning |
|---|---|
| Bedöma risk i varuflöden | Förmåga |
| Genomföra riskbaserad deklarationskontroll | Process |
| Dokumentera kontrollresultat | Rutin eller instruktion |
| Riskindikator | Informationsobjekt |
| Kontroll krävs vid hög risknivå | Regel |
| Kontrollhandläggare | Roll |
| Digital riskanalyskomponent | Systemstöd |

Princip: samma vardagsord, till exempel “kontroll” eller “risk”, kan behöva delas upp i flera tydligare kandidater.
